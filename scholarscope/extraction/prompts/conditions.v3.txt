Extract ONLY conditions, a list of stated claims (no status field).
Each has kind, value, required, applies_to, evidence and notes. Unstated conditions
are not entries. Use min_gpa with {value, scale}, language with {logic, options},
or the other named kinds with the literal value shape the page states. Every
condition needs evidence. Keep required false when explicitly not required.

Never emit a language condition without a named test or score. Use kind "other"
with the requirement sentence as value, never invented tests, scores or empty options.
Fictional example: "applicants must meet the language requirement of their chosen programme"
-> kind other with that sentence as value.
degree_held means a degree the applicant must already hold or will obtain,
never the programme for which the award is offered. Fictional example: "Example
award supports doctoral study; applicants will obtain a bachelor degree before entry"
-> degree_held describes the bachelor prerequisite, not the doctoral programme.
residency is only for place-of-residence or stay requirements. Tuition-fee
classification and visa rules use kind "other", never residency.
Do not emit two conditions that restate the same quote.

Copy quotes verbatim, at most 400 characters each: choose the shortest passage
that carries the fact; use several quotes for facts split across passages.
Cite passage_id exactly as supplied. Never infer or guess. Do not set verification.
For ordinary fields use status absent, value null, evidence [] when unstated.
Use in_linked_document with linked_url, value null and evidence [] when the page
points elsewhere; never follow links. Ambiguous fields have value null and quotes;
put conflicting candidates in notes. Present fields need nonempty values and quotes.
Return every schema property; use null for missing nullable properties.

Normalize values only (never rewrite quotes): dates YYYY-MM-DD, with a year only
when explicitly stated in the sentence, row or directly governing heading. Never
infer the year from today. Times HH:MM (24 hour); leave midnight/end of day/close
of business uninterpreted with time null. Timezone only if explicitly named;
unknown if time is given without a zone, null if time is null. JST -> Asia/Tokyo,
Beijing time -> Asia/Shanghai, CET -> UTC+01:00, CEST -> UTC+02:00. Other abbreviations
become an explicit UTC offset only when unambiguous, otherwise unknown with notes.
Money: amount/currency/period as stated, never converted; up to -> amount_max.
GPA: {value, scale} as stated; missing scale -> condition kind other, never assume
4.0. Degree levels require explicit words: master/MSc/MA/laurea magistrale -> master;
PhD/doctoral -> phd; graduate alone is ambiguous. Nationality wording stays verbatim.
Closed/stale cycles stay as printed; never modernize them. Explicit not required
conditions use required false. Recommenders explicitly not required use counts 0.
For language alternatives use logic any or all with options exactly as stated.
Use only the fictional Example Excellence Scholarship for illustrative reasoning;
no outside knowledge or examples may supply missing facts.

Never output a language condition with an empty options list. If proficiency in English or another language is required but no test or score is named, emit kind "other" with that sentence as value. Never invent tests or scores.
